# 週日場記・場次人員管理 PWA

單機使用、免登入、資料全部存在你瀏覽器本機（IndexedDB）的週日場次管理工具。

## 這是什麼

依照規格書實作的完整功能：
- 季度（3 個月一季）與場次管理，建立季度自動產生全季場次
- 場次人員名單（男/女分組），季打管理獨立分頁控制出席/請假（預設出席）
- 季打名單設定，加入時自動帶入季度預收金額，並可批次多選加入
- 冷氣使用紀錄與支出，分攤人數可依場次個別調整
- 繳費方式紀錄（－ 代表未繳）與批量調整（季打與臨打皆可）
- 費用管理與批量調整（臨打）
- 場次／季度統計：應收、已收、支出、應收盈餘、已收盈餘（皆含季打已收金額）、依繳費方式加總
- 季打退款／應補收自動結算，退費顯示「－」、補收顯示紅色「＋」，並可點擊姓名查看/批量調整每場出席紀錄

## 如何使用（本機開啟）

因為瀏覽器安全限制，Service Worker（離線快取）與 IndexedDB 在 `file://` 直接開啟時可能無法正常運作，**建議用一個簡單的本機伺服器來開啟**：

### 方法一：使用 Python（大多數電腦都有）
```bash
cd 這個資料夾
python3 -m http.server 8080
```
然後用瀏覽器打開 `http://localhost:8080`

### 方法二：使用 Node.js
```bash
cd 這個資料夾
npx serve .
```

打開後，手機瀏覽器可以用「加入主畫面」／桌面瀏覽器網址列的「安裝」圖示，把它安裝成一個 App。

## 如何部署到網路上（讓手機直接連網址使用）

這是純前端靜態網站，沒有後端，可以直接放到任何靜態網站託管服務，例如：
- **GitHub Pages**：把這個資料夾內容 push 到一個 repo，開啟 GitHub Pages 指向該分支即可。
- **Cloudflare Pages / Netlify / Vercel**：把資料夾拖拉上傳即可部署，幾分鐘內拿到一個網址。

部署後用手機瀏覽器打開該網址，一樣可以「加入主畫面」安裝成 App。

## 資料備份

所有資料只存在單一瀏覽器、單一裝置裡。**強烈建議定期到「設定」頁面按「匯出 JSON 備份」**，把備份檔存到雲端硬碟等地方。若要更換裝置或清除瀏覽器資料前，也請先匯出備份，之後可以用「匯入 JSON 備份」還原。

## 檔案結構
```
index.html              主頁面
manifest.webmanifest    PWA 設定檔
sw.js                   Service Worker（離線快取）
css/styles.css          樣式
js/
  main.js               入口、路由註冊
  router.js             簡易 hash router
  db.js                 IndexedDB 封裝
  calc.js               核心計算邏輯（統計、退款試算）
  utils.js              共用工具函式
  views/                 各頁面（首頁、季度、場次、人員、設定）
icons/                  App 圖示
```

## 已知待確認事項（規格書中已定案，若要之後調整可回頭修改 calc.js）
- 季打「中途加入」試算：固定用「季初預估值」計算，不使用實際場次均價。
- 季打退款：以「(場地費＋冷氣費) ÷ 季打人數快照」的場次人均分攤成本計算，請假場次份額視為 0（全額退還）。
